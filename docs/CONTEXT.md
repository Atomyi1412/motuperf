# iOS 性能采集工具上下文

本项目用于构建一个面向测试人员的 iOS USB 性能采集工具，优先覆盖微信小游戏运行场景下的实时帧率、卡顿和内存趋势观察。

## Language

**USB 模式**:
设备通过 USB 连接到本机，由本机工具读取 iOS 设备和目标进程的性能数据。第一版不包含 Wi-Fi 连接、远程设备池或云端采集。
_Avoid_: 远程测试, 云测试, 多机并发

**微信小游戏性能**:
在 iOS 设备上打开微信并运行指定小游戏时，采集微信宿主进程及系统可见渲染性能数据，用于近似评估小游戏运行体验。
_Avoid_: 小游戏独立进程性能, 源码内埋点性能

**目标进程**:
采集工具绑定并展示性能数据的 iOS bundle 或进程。微信小游戏第一版默认目标为微信宿主应用 `com.tencent.xin`。
_Avoid_: 测试对象, 游戏对象

**实时曲线**:
采集期间持续追加刷新 FPS、Jank、BigJank 和内存数据的时间序列视图。第一版只要求本地实时展示，不要求云端看板。
_Avoid_: 离线报告, 云端报表

**Jank**:
帧时间异常导致的卡顿计数或卡顿事件。第一版允许优先使用采集后端直接输出的 `jank` 和 `big_jank` 字段；若后端只提供 FPS，则不伪造精确 Jank。
_Avoid_: 掉帧率, 低帧率

**本地导出**:
将一次采集的原始采样和基础汇总保存到本机文件，第一版至少支持 CSV，JSON 作为可选补充。
_Avoid_: 云同步, 自动报告系统

**设备内部热表现**:
使用 MoTuPerf 可见的设备级 Battery Temperature 温升、Thermal State 变化及对应性能趋势描述设备内部热压力；不等同于机身表面、CPU 或 GPU 的真实摄氏温度。
_Avoid_: 机身温度, 芯片温度, 手感温度

**Battery Temperature**:
iOS Diagnostics IORegistry 返回的设备电池温度。正式统计只使用带真实更新标志、来源和设备级范围的读数。
_Avoid_: 表面温度, CPU 温度, GPU 温度

**Thermal State**:
iOS 系统热状态等级，取值为 `0 nominal`、`1 fair`、`2 serious`、`3 critical`。它表示系统热压力等级，不是摄氏温度。
_Avoid_: Thermal Status, 温度值

**A/B 配对**:
同一台实体设备在受控条件下分别运行自研游戏 A 与竞品 B，并比较同轮次内部热表现；不同设备的绝对温度不直接合并。
_Avoid_: 跨机型温度排名

## Flagged Ambiguities

**小游戏进程**:
iOS 上微信小游戏通常运行在微信宿主环境中，外部 USB 性能通道不一定能识别到独立小游戏进程。后续用 **微信小游戏性能** 表示“运行小游戏时的微信宿主进程/系统渲染性能”，除非确认存在可稳定选择的独立进程。

## Example Dialogue

Developer: 第一版我会把 `com.tencent.xin` 作为默认目标进程，并在界面上提示用户先手动打开小游戏。
Domain expert: 可以，先看运行小游戏时微信进程的 FPS、Jank 和内存曲线，后续再考虑小游戏级识别。
