# MoTuPerf v0.24.2 优化与后续建议

日期：2026-09-17

## 本轮已完成

1. 采集隔离：每轮独立采集服务和截图服务，样本、截图、状态、失败和断线通知绑定采集轮次。停止排空已接收样本，旧回调不能影响新轮次。
2. 中断诊断：记录任务启动/结束/取消/异常、原始停止原因、持续时间、样本数量及指标最后实际更新的接收时间。连接探测失败记为“未知”，不会直接当作拔线。
3. 长会话显示：合并界面刷新，共用历史有序视图，缩短附近样本查找，缓存曲线路径；游标移动不重新整理整段历史。原始数据、计算公式、真实零值、缺测和峰谷保留。
4. 设备提示：Android/iOS 分别显示授权、连接、组件和超时问题；详情读取失败仍保留基本设备；诊断换行，修复入口不挤出边界。
5. 更新记录：本地、客户端最新三个版本、飞书在线文档同步 v0.24.2。

## 验证

- .NET Release 自动化 180 项通过，Python 278 项及 14 个子测试通过。
- 同机 10 万条模拟样本：追加 200 条从约 4.49 秒降到 1.7 毫秒；移动游标重绘 50 次从约 2.85 秒降到 8.7 毫秒。仅代表该基准，不等于真机整段采集速度。
- 三主题、两种主窗口尺寸共 12 张渲染截图；新版主窗口实际启动并确认 v0.24.2。用户按 Esc 停止界面自动操作，因此设备选择的完整点击路径未完成。
- 本轮未完成长时间真机采集、实际拔线重插、同事电脑和 macOS 实机验收。保留现有 CS9057 分析器兼容警告、两项 pyOpenSSL 弃用警告记录。
- Windows 本地安装包已生成：`motuperf_cross_platform/dist/installer/MoTuPerf-Setup-v0.24.2.exe`，安装包与程序版本、SHA-256 一致，随包 Python/iOS 模块导入和 ADB 启动检查通过。未覆盖当前安装或发布到 GitHub。

## 尚未修改与建议顺序

| 优先级 | 方向 | 场景与建议 | 验收重点 |
| --- | --- | --- | --- |
| 高 | 进程自动切换边界 | target_rebound 目前更新 PID，旧 CPU/内存缓存可能短暂沿用；确认换进程后清理相关缓存并标记边界 | 不把旧 PID 数值标成新 PID，连续现场时间轴保留 |
| 高 | 数据可信度提示 | 缺测、降级来源、目标未验证目前不易判断；提供来源和有效覆盖率摘要 | 缺测不补零，来源变化可追溯 |
| 中 | 大现场文件加载 | 改善分阶段进度、取消和截图后台加载失败反馈 | 保留曲线优先打开，不因等待全部截图拖慢首屏 |
| 中 | 保存与导出 | 增加阶段百分比、剩余空间检查与明确失败恢复 | 失败不破坏旧文件，已保存与仍在处理清晰可见 |
| 中 | 长时间截图内存 | 缩略图按可见区域缓存，离屏释放，需要时重载 | 多小时采集和浏览时内存增长可控 |
| 中 | 数据目录自检 | 启动检查只读目录、外置盘掉线和空间不足 | 给出具体原因和可选目录，不静默换路径 |
| 中 | 更新下载恢复 | 增加有限重试、断点续传、失败恢复 | 保留校验哈希与原安装路径 |
| 中 | 可重复性能验收 | 覆盖全指标绘图、迟到数据、缺失段及长时间刷新；统一 SDK/分析器 | 性能改善与显示真实性同时通过 |
| 中 | 真机回归矩阵 | Android/iOS 不同系统与 macOS，覆盖休眠、拔线、进程重启 | 每个场景留存日志、现场文件和版本 |

本轮仅落实用户确认的三类优化；以上条目是后续工作，不代表已经完成。
