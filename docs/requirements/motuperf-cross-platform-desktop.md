# MoTuPerf 跨平台桌面版需求

状态：confirmed

## 1. 用户目标

测试人员在 Windows 或 macOS 上使用同一套 MoTuPerf 操作界面，通过 USB 选择 iOS/Android 设备、APP 和进程，采集真实性能数据，查看联动曲线与截图，并保存现场或导出表格。

## 2. 产品原则

1. 保留已可用的 Windows WPF `v0.4.65`，跨平台开发失败时仍可恢复和继续使用旧版。
2. Windows 与 macOS 共用指标语义、现场格式和主要交互，不维护两套互相漂移的数据算法。
3. 缺失或不支持的数据保持不可用，不通过零值、插值或平滑制造完整曲线。
4. 跨平台不是“能编译”即可；每个平台都需要真实运行和设备验收。

## 3. 功能范围

- 选择并刷新设备、APP 和进程，支持搜索、推荐和启动 APP。
- 按所选 PID 采集进程 CPU 和内存，按真实显示源采集 FPS、FrameTime、Jank 和 BigJank。
- 采集设备温度；iOS 支持 Thermal State 时显示 `0/1/2/3`。
- 每 3 秒异步截图，并与全部指标共享时间选择。
- iOS 截图必须记录设备在截图时的界面方向；当系统返回竖向 PNG 画布但设备实际为横屏时，缩略图和大图查看器按方向旋转显示，原始 PNG 不改写。
- 曲线支持实时跟随、历史拖动/缩放、同一时刻联动和多序列显隐。
- 截图支持缩略图、双击大图、缩放、适应、上一张/下一张。
- 支持 `.motuperf` 保存/打开和 CSV 导出。
- 支持设备断开、主动停止和采集中退出时的保存提示。

## 4. 平台范围

- Windows：继续支持 `win-x64`。
- macOS：首期只支持 Apple Silicon `osx-arm64`（M1/M2/M3/M4）。
- Intel Mac `osx-x64` 不属于首期发布和验收范围，未来可在不分叉业务代码的前提下增加独立安装包。
- Linux 不属于首期发布范围。

## 5. 兼容要求

- 跨平台版可读取现有 session v1-v5。
- 新现场文件保存每张截图的方向值；旧现场没有方向字段时按 PNG 宽高回退，不能因此拒绝打开。
- Windows/macOS 对相同现场文件显示相同的关键指标、单位、时间和截图。
- Windows/macOS CSV 字段语义一致；平台专属来源可不同，但必须被明确标注。
- 旧 WPF 工程和 `v0.4.65` 安装包不得被覆盖。

## 6. 质量与验收

- 共享核心通过单元测试和 session 往返测试。
- Windows 完成桌面 UI、真实设备采集和发布包验证。
- macOS 完成 `.app`/安装包运行、USB 设备检测、真实采集、截图、文件操作和退出流程验证。
- 保存/导出必须通过真实点击路径验证。
- 主要桌面尺寸无文字重叠、横向溢出或遮挡。

## 7. v0.24.2 采集可靠性与长会话性能

- 用户确认本轮只修改采集生命周期与诊断、长时间 UI 刷新与绘图、Android/iOS 检测错误提示。
- 停止后旧轮次的样本、截图、状态及断线回调不得污染新轮次；停止保留已经接收到的样本。
- 提升显示性能但不改变 FPS/Jank/CPU/内存等算法，不平滑峰谷、不把缺测补零、不精简现场文件的原始样本。
- 设备检测应给出可操作的分平台原因，可选详情失败不能隐藏已经发现的设备。
- 真实拔线、长时间设备采集、macOS 验证必须与模拟数据及 Windows 窗口验证分开记录。
